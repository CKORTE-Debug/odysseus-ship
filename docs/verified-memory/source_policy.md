# Source Policy

Use the highest authority available. Prefer current official sources over summaries, blogs, forums, or AI-generated pages.

## IT / software
1. Official vendor documentation
2. Official release notes / changelog
3. Official GitHub repository or issue tracker
4. Vendor support forums or official community posts
5. Reputable technical blogs
6. Wikipedia for background only
7. Reddit/forums for clues only, never final authority
