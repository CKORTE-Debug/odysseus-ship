# Privacy Policy for Online Verification

Local document content is private. Do not send local document text to web search.

## Never include in web search queries
- Client names
- Employee names
- Personal names from local docs
- Email addresses
- Phone numbers
- Addresses
- Internal domains
- IP addresses
- Hostnames
- Ticket numbers
- Contract numbers
- File paths
- Internal filenames
- Project codenames
- Exact private error logs unless user approves

## Allowed in web search
Vendor/application/product names, such as Microsoft, Windows, Intune, Entra, Teams, SharePoint, Surface, Adobe, Apple, Google, Cisco, Fortinet, Zoom.
