# Staleness Policy

## Default
If a memory has no last_verified_at date, treat it as unverified.

## Suggested stale periods
- software_behavior: 60 days
- microsoft_365: 30 days
- pricing: 3 days
- news: 1 day
- game_patch: 7 days
- law_or_regulation: 30 days
- internal_sop: 180 days
- personal_preference: never
- historical_fact: never

## Stale memory behavior
Stale memories may be used as leads but not as confirmed facts. If stale memory is relevant and online verification is allowed, verify before answering. If verification is not possible, label the answer as based on stale or unverified memory.
